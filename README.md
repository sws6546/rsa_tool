# RSA Tool

Prosty projekt webowy do generowania i analizowania kluczy RSA. Pozwala użytkownikowi tworzyć klucze, szyfrować i deszyfrować wiadomości oraz wizualizuje wybrane aspekty działania algorytmu RSA.

## Funkcje

- Generowanie kluczy publicznych i prywatnych RSA.
- Szyfrowanie tekstu publicznym kluczem.
- Deszyfrowanie tekstu prywatnym kluczem.
- Prosty, intuicyjny interfejs webowy.

## Jak uruchomić projekt?

1. **Pobierz repozytorium**
   ```
   git clone https://github.com/sws6546/rsa_tool.git
   cd rsa_tool
   ```

2. **Zainstaluj zależności**
   
   ```
   npm install
   ```

3. **Uruchom aplikację developerską**
   
   ```
   npm run dev
   ```

4. **Otwórz aplikację w przeglądarce**

   Aplikacja jest dostępna pod adresem: [http://localhost:5173](http://localhost:5173)
