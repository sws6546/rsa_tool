# RSA Tool

A simple web project for generating and analyzing RSA keys. It allows the user to create keys, encrypt and decrypt messages, and visualizes selected aspects of the RSA algorithm.

## Features

- Generation of RSA public and private keys.
- Encryption of text with a public key.
- Decryption of text with a private key.
- Simple, intuitive web interface.

## How to run the project?

1. **Clone the repository**
   ```
   git clone https://github.com/sws6546/rsa_tool.git
   cd rsa_tool
   ```

2. **Install dependencies**
   
   ```
   npm install
   ```

3. **Run the development application**
   
   ```
   npm run dev
   ```

4. **Open the application in your browser**

   The app is available at: [http://localhost:5173](http://localhost:5173)
